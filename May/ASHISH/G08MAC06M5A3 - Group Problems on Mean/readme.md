# G08MAC06M5A3 — Group Problems on Mean

Interactive bilingual applet following the supplied PowerPoint storyboard.

- `index.html`: Indonesian entry point
- `index-en.html`: English entry point
- `data.js`: lesson values, screen copy, hints, equations, and translations
- `components/GroupBuilder`: addition/subtraction group model
- `components/RuleExplorer`: multi-group rule slider
- `components/ProblemSolver`: reusable identify–plan–solve engine for all three problems
